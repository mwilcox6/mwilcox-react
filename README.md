# Todo List App

This is a React todo list app built with Vite.

## Installation Instructions

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone this repository and open the project folder:
   ```bash
   git clone <repository-url>
   cd mwilcox-react
   ```
3. Install the project dependencies:
   ```bash
   npm install
   ```

## How to run the development server

From the project folder, start the Vite development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173/`) in your browser.
